# Publication examples

- `pms-application-configuration.example.json` is a sanitized version of the VM's PMS configuration. The historical endpoint and controller password were replaced. A likely typo in `customAdapterClass` (a space after `clients.`) was removed; the result was not runtime-tested.
- `nonrtric-recipe-excerpt.yaml` records selected values from the VM's current J-release recipe. It is intentionally incomplete.
- `policy-type-20008.json` is reconstructed from the [J-release HackMD note](https://hackmd.io/@_Rheq0BSRpaANOaleSyL2Q/S1Dij0ABR). A corresponding JSON file was not found in the scanned VM paths.

These files are explanatory examples. They are not a turnkey deployment bundle.
